real-time progress va natijalar. Loyihaning birinchi real-time bosqichi.

BAJARILGAN ISHLAR
-----------------
1. Domain
   - RoomCodeGenerator: 8 belgi, ABCDEFGHJKLMNPQRSTUVWXYZ23456789 alfaviti
     (I, O, 0, 1 yo'q — chalkashlik oldini olish).

2. Application (CQRS)
   - IApplicationDbContext ga Rooms, RoomPlayers qo'shildi.
   - CreateRoomCommand [auth]: noyob kod (Redis da mavjudligini tekshiradi),
     Room + host RoomPlayer yaratadi, kodni Redis da 30 daqiqa TTL bilan
     saqlaydi (room:{CODE} → roomId).
   - GetRoomQuery(code): Redis TTL → DB fallback, RoomDto qaytaradi.

3. Infrastructure
   - RoomLiveState (singleton, in-memory): live xona/lobby/poyga holati
     (ConcurrentDictionary). RoomLive + RoomPlayerLive modellari.

4. Web (SignalR)
   - LobbyHub (/hubs/lobby) — to'liq friends-room hayot sikli:
       JoinRoom(code, displayName) — guest (anonim) ham qo'shila oladi,
         host Context.User (JWT cookie) orqali aniqlanadi.
       StartRace(code) — faqat host; matn tanlaydi (Sentences), countdown.
       ReportProgress(code, progress, wpm) — guruhga broadcast.
       FinishRace(code, wpm, accuracy) — joy belgilash, hammaga; barcha
         tugagach RaceFinished + Room.Status=Finished persist.
       LeaveRoom / OnDisconnectedAsync — o'yinchini olib tashlash + broadcast.
   - RoomsController: POST /api/rooms [auth] (yaratish),
     GET /api/rooms/{code} (tekshirish, topilmasa 404).
   - Program.cs: MapHub<LobbyHub>("/hubs/lobby").

5. Frontend
   - /Rooms: xona yaratish (→ /Room?code=...) / kodga qo'shilish. rooms.js.
   - /Room: SignalR client (CDN @microsoft/signalr 8.0.7), lobby (o'yinchilar
     + progress barlar), host "Boshlash" tugmasi, 3-2-1 countdown overlay,
     real-time typing (keystroke handler, progress hisoblash, throttled
     ReportProgress 400ms), natijalar (medal + wpm/accuracy). room.js.
   - Navbar: "Xona" linki. CSS: room kartalar, progress bar, countdown, ranks.
