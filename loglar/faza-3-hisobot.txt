BAJARILGAN ISHLAR
-----------------
1. Auth
   - IIdentityService (Application) + AuthService (Infrastructure):
     UserManager<ApplicationUser> ustida, BCrypt hasher orqali.
   - RegisterCommand + validator (username 3–32 [a-zA-Z0-9_], email,
     parol ≥8, RegionCode validatsiya — UzbekistanRegions).
   - LoginCommand + validator (username yoki email + parol).
   - Lockout: 5 noto'g'ri urinish → 15 daqiqa blok (Identity lockout,
     AccessFailedAsync / IsLockedOutAsync / ResetAccessFailedCountAsync).
   - AuthController: POST register/login (JWT cookie o'rnatadi),
     POST logout (cookie o'chiradi), GET me ([Authorize]).
   - Cookie: HttpOnly, Secure=Request.IsHttps, SameSite=Lax, Expiry.
   - Razor: /Login, /Register (14 hudud select), auth.js (fetch + redirect).
   - Navbar: kirgan bo'lsa username + "Chiqish", aks holda "Kirish/Ro'yxat"
     (server-side User.Identity.IsAuthenticated). Logout JS.

2. Leaderboard
   - ILeaderboardService (Application) + LeaderboardService (Infrastructure):
     Redis Sorted Set, key=lb:{timeMode}, member=userId, score=bestWpm.
   - UpdateAsync — yangi PersonalBest da chaqiriladi (SubmitResult handler ga
     hook qo'shildi).
   - GetAsync — top 50 (Redis) + DB dan username/region/avatar/accuracy,
     joriy foydalanuvchi rank (SortedSetRank), top da bo'lmasa alohida qator.
   - Redis bo'sh bo'lsa — DB PersonalBest lardan RebuildAsync (cache warm-up).
   - GetLeaderboardQuery + handler.
   - LeaderboardController: GET /api/leaderboard?timeMode=Thirty.
   - Razor: /Leaderboard (5 tab 10/15/30/60/120), leaderboard.js
     (medal 🥇🥈🥉, joriy user highlight, separator "···" + user qatori).

3. Tuzatish
   - Middleware tartibi: UseSerilogRequestLogging endi ApiExceptionMiddleware
     dan tashqarida — kutilgan 400/401 toza loglanadi (avval 500+stack edi).
